本方案完全基于 d:/Projects/androidapk 现有三层架构（core 领域算法 / data Room Flow / ui Compose MVI）推导， 覆盖 4 条路由、5 类复习评级、7 档记忆状态机与超量顺延调度，给出可落地的布局、交互、状态与适配规范。

0设计推导依据

界面不是凭空画的，每一处都能在代码里找到出处。下表是"代码事实 → 界面约束"的映射，后续所有设计都以此为锚点。

代码落点约束 / 能力对界面设计的直接影响
Screen.kt4 条路由导航骨架 = 1 主 Tab（知识库）+ 1 沉浸页（复习）+ 1 设置 + 1 详情下钻
ReviewStage7 档：1/2/4/7/15/30/60 天档位是核心可视资产 → 必须"徽章化"常驻复习卡与详情卡
ReviewRating5 枚举复习页底部固定 5 按钮，颜色语义全局唯一
RolloverEngine输出 todayBatch / deferredTasks / totalPendingCountBanner 需同时表达"今日量 + 顺延量 + 总量"三层信息
DashboardViewModel跨天 ∧ 未弹过 ∧ limit>0 ∧ due>0 才弹窗看板弹窗是"每日至多一次"的一次性浮层
UserSettingsEntitydailyReviewLimit ∈ [0,50]，0 = 停用Banner 与复习页必须有独立的"停用"状态
MathView / MathTextPreprocessorLaTeX 高保真渲染正文区不可纯 Text 截断；列表用 Unicode 降级

设计总纲：复习是高认知负担行为，界面原则是 零噪音 · 零逾期焦虑 · 零惩罚感。 高饱和色只出现在"评级按钮"这一处，其余一律低饱和中性面；文案统一用"顺延 / 待复习 / 继续保持"，禁用"逾期 / 失败 / 落后"。

2整体页面布局与导航结构

现状是 TopAppBar + FAB 的"中心辐射式"导航。方案建议升级为 底部 3 Tab，把"复习"从 Banner 单点入口提升为常驻一级入口， 同时保持复习页的沉浸性（进入时隐藏底部导航）。

2.2 导航规则

① 复习 = 沉浸页

进入 review 隐藏 NavigationBar，仅保留 TopAppBar 返回键。退出不弹"放弃确认"——复习无副作用。

② 详情 = 下钻页

memo_detail 不显示底部导航，返回键 popBackStack()。

③ 状态保持

Tab 切换用 saveState/restoreState/launchSingleTop，知识库的搜索词、筛选标签、滚动位置往返不丢。

④ 系统返回键

详情 → 知识库；复习 → 知识库；知识库 → 退出应用。

⑤ 深链预留

memo_detail/{id} 已参数化，未来可接 App Shortcut / 桌面小组件。

⑥ 转场

全站横向 Slide 300ms（已实现）；复习页建议改为淡入淡出，避免"翻页感"打断心流。

关键约束

  • Edge-to-Edge：Android 15/16 强制。Scaffold 处理 systemBars insets；FAB 与底部按钮需叠加 navigationBarsPadding()，避免被手势条遮挡。
  • 滚动行为：知识库列表滚动时 TopAppBar 容器色过渡到 surfaceContainer（scrollBehavior）。
  • FAB：仅知识库页显示，右下角距边 16dp；不做 auto-hide，避免误触丢失入口。
  • 底部按钮区（复习页）：固定不随卡片滚动，卡片区自行 verticalScroll。
  • 触控目标：所有可点元素 ≥48×48dp。

复习交互要点

底部按钮区固定

不随卡片滚动；卡片区 verticalScroll 自适应。提交后 180ms 淡出上移切入下一张，进度条与 n/m 同步 +1。

笔记抽屉三级

展开 → 展示态（Surface + 铅笔）→ 编辑态（TextField + 取消/保存）。保存后回展示态并 Toast。

草稿保护

点击评级时若仍在编辑态，自动保存草稿 + Toast「笔记已自动保存」，避免用户输入丢失。

评级后果可见

每个按钮的无障碍文案需说明后果，如「记住：前进一档，30 天后再复习」，降低误操作。

智能调度与顺延规则说明

删除 → 确认 → deleteMemo → SQLite CASCADE 清任务 → Flow 移除 → Snackbar / 详情页 isDeleted → Toast + popBackStack

F5 搜索筛选

关键词 / 标签 → combine + flatMapLatest → searchMemos → 命中刷新 / 无命中等空态 B；再点同一标签 = 取消筛选

F7 复习中记笔记

展开 → 铅笔 → 编辑 → updateNotesOnly → 同步本地队列 → 回展示态 + Toast「笔记已保存」

配置上限

设置 → 拖动 / 快捷 Chip → updateDailyLimit → 首页 Banner 与复习队列实时重算（Flow 驱动，无需重启）

空状态与异常态五原则：
① 每个空状态必须带一个可执行 CTA（新增 / 清空筛选 / 去设置 / 重试），杜绝死胡同；
② 文案不制造焦虑——禁用"逾期/失败/落后"，统一"顺延/待复习/继续保持"；
③ 视觉统一：outline 色 72dp 线性图标 + bodyLarge 主文案 + bodySmall 说明 + 次级按钮，垂直居中、左右留 32dp；
④ 异常态必须可恢复：提供重试，或依赖 Flow 在数据变化后自动恢复；
⑤ 空状态不遮挡主功能：TopAppBar、底部导航、FAB 保持可用。

9.4 其他适配维度

字体缩放

全量使用 sp；支持系统 0.85×–2.0×；在 1.3× 下复核不截断；复习按钮文字支持换行或自适应。

触控目标

可点元素 ≥48×48dp；Chip 高 32dp 由父级 padding 补足；评级按钮高 ≥48dp。

屏幕旋转

允许旋转；ReviewUiState 由 ViewModel 持有，旋转不丢进度；草稿用 rememberSaveable。

深色模式

isSystemInDarkTheme() 驱动；评级色在深色下保持原值，对比度 ≥4.5:1。

动态取色

当前 dynamicColor = false 保持品牌一致；预留设置开关供 v1.1。

Edge-to-Edge

Android 15+ 强制；enableEdgeToEdge() + Scaffold insets；FAB 加 navigationBarsPadding()。

折叠屏铰链

WindowInfoTracker 检测 FoldingFeature.isSeparating，按铰链位置分栏，避免卡片横跨铰链。

多窗口 / 桌面化

Android 16 自由缩放窗口下 WindowSizeClass 实时重算，布局无缝切换。

尺寸资源

圆角与边距写入 dimens.xml，提供 values-sw600dp / values-sw840dp 覆盖。

10无障碍与可达性

语义与朗读

所有 Icon 必填 contentDescription；评级按钮补充"后果说明"语义（如「记住：前进一档，30 天后再复习」）；装饰性图形标为 null。

对比度

正文与背景 ≥4.5:1，大字与图标 ≥3:1；评级按钮统一白字 + 深色底，已满足。

焦点顺序

TalkBack 顺序：TopAppBar → 内容 → 底部按钮；复习页保证 5 个评级按钮可达且不因滚动被隐藏。

触控与误操作

删除等破坏性操作二次确认；评级按钮间距 ≥8dp，避免连点误触。
